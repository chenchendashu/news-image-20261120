One image that sums up the world news of Friday, 20 November 2026: the Trump-Putin-Xi peace declaration, the ICJ ruling that Myanmar committed genocide against the Rohingya, fossil fuels cut from the COP31 draft deal, Russia's missile barrage on Kyiv, Anthropic's landmark AI IPO, and the day's other headlines — drawn as a one-page newspaper front page.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024×1024, 135 KB) to the output directory, byte-identical on every run. `render.py` is the Pillow script that drew the image from the day's reported news; re-running it regenerates `entry.png` deterministically.
